# 公开文本开发集检索结果（2026-10-05）

当前证据支持保留**词法检索 + 同会话前后各 1 条原文**作为继续比较的基线。离线 E5 的等权和 0.5 权重都没有在两个小开发子集、各个返回预算下稳定胜出。尚未选定最终方法，也没有官方 AML 分数、回答正确率或 Full 容量证明。

本报告只发布汇总统计、版本和运行标识，不含题目、答案、历史原文、用户标识或机器私有路径。所有数字按正文评分口径 `public-full-turn-body-only-v2` 离线重评已有响应；没有为重评再调用检索、embedding、Answer 或 Judge。

## 数据与边界

| LoCoMo-Refined 文本子集 | 1 会话 / 82 题 | 568 | 98 | 39 / 82 |

准备时固定种子 `aml-public-proxy-2026-v1`，分组 60/20/20。LongMemEval 的 470 个有召回标注实例按构造历史及共享证据 session 分组，开发/验证/留出为 283/94/93 题；已排除 30 道无召回金标的拒答题和 11 条空白非证据历史消息。LoCoMo 10 个会话整体分 6/2/2，排除 521 道多模态题和 2 道证据无法解析/定位的题，859 道文本代理题分为 547/183/129。本次只取固定开发列表的前 20 历史和前 1 会话，不代表完整开发集。

验证和留出检索均未运行。LongMemEval 没有持续真实用户 ID，上游 filler session 可跨 split 复用（准备统计为 2,362 个原生 session ID），已标注证据 session 的复用仍保持同组；不能声称全原始语料完全隔离。LoCoMo 的 82 题来自同一会话，观察彼此相关。

Add 只接收历史角色、原文、原始说话者/会话日期和不含数据集名称的隔离标识。未来问题、答案、证据编号、has_answer、摘要和观察均留在评分侧。Search 只接收原始问题和接口隔离字段，不注入 question_date。原始日期文字保留；无时区日期采用 UTC 作为毫秒编码约定。分块上限 20 消息 / 2,000 空格词，是代理近似，不是官方 tokenizer。

## 评分口径与修复

All 为每题全部标注证据 turn 完整覆盖的比例；Macro 为每题 turn 覆盖率再按题平均；Any 为至少覆盖一个完整证据 turn 的题目比例。仅折叠空白，不改大小写、标点或事实文字。来源核验还要求映射到实际 Add 位置或稳定原始消息 ID，并有该消息的完整正文。session 命中单独诊断，不能代替 turn 覆盖。API 失败保留在所有请求的分母中。

旧实现误把生成的 source JSON 纳入文本回退，短金标如 `assistant` 可仅由 metadata 误命中，伪造已知 anchor ID 也有类似问题。正文 v2 抽取每个独立来源的实际正文，排除 wrapper/邻接结构标签；完整原文里的合法 source 形状引用保留，禁止跨两个 wrapper 拼接成假 turn。无法核验来源时，只允许历史中唯一出现的完整金标文字回退。17 项离线回归覆盖这些边界及未来标签不进 Add、分组拆分和环境配置污染；自造回归用例不计入公开数据成绩。

7 次实际运行的原始 summary 和 retrieval 保留不改写；最早 5 次是旧口径，后 2 次已记录正文 v2。当前实现离线重评后，所有 k 的命中数量和来源核验数量变化均为 **0**，这批样本数值没有受该缺陷影响。新版 comparison 同时记录旧口径标识、评分源文件 hash、数据一致性检查和变化计数，作为可审计的新结果。

| 数据 | 相对词法半径 1 | k=20 新增 / 丢失完整覆盖题 | k=100 新增 / 丢失完整覆盖题 | 64k 字符新增 / 丢失完整覆盖题 |

| locomo_refined | 词法，邻接半径 0 | 0 / 11 | 0 / 13 | 2 / 13 |

LoCoMo 中，半径 1 比半径 0 在匹配 k 和这些字符预算下更好，值得保留。E5 等权在两个数据集的 k=20 都退步，虽在 k=100 提升 All，证据量很大且预算受限时不稳定。0.5 权重也没有消除退步，不能凭某个最大 k 或单一字符预算选最终方案。没有按数据集、用户或问题类别设置不同语义权重。

下一步应在固定候选与真实预算明确后独立做回答评测和云机负载验收；取得模型额度、连通部署环境前，不把这些召回数字折算成 AML Overall。当前报告完成后没有继续扩展验证/留出实验。

## 真实运行配置与审计

词法路径显式禁用 embedding。语义路径为已下载的 `intfloat/multilingual-e5-small`，revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`，CPU、384 维、L2、`query: ` / `passage: `，384-token 原文窗口、64-token 重叠、512 最大模型长度，长查询按分段向量均值归一化。线程 2、batch 8、推理并发 1，强制离线，没有付费 HTTP provider。词法 RRF 权重为 1，语义全局权重为 1 或 0.5。

只读模型/索引审计验证 10 个模型文件的大小与 SHA256，4 次语义运行实际数据库的 fingerprint、384 维 float32 长度均匹配声明，并各核验 16 个确定顺序样本的 L2 范数。向量段数：LoCoMo 每次 568；LongMemEval 每次 13,263。检查不是效果指标。

早期运行只记录部分启动配置，其模型窗口/前缀实际值已由数据库指纹核对，不能倒称它们当时记录了全部环境。当前工具已清理继承的 `MEMORY_EMBEDDING_*` 配置和外部密钥，显式固定前缀、窗口、重叠、段数上限、队列/操作时限，保存非敏感启动配置，避免未来实验静默受环境影响。此次增强未重新运行数据集。

服务版本：前 5 次 `632edb2b0a726f7835a2eebda4a9eaba74ea4361104b6ad953e6cb03534db800`；0.5 权重两次 `5a2d049d857ebc00ee7af51877af8b91681ba952eb8f2fee1d22a817dd9ec0c9`，新增显式权重参数。每次开始/结束服务 hash 一致，各次运行配置保留。最早两个词法运行只记录源文件 hash，没有启动代码快照；后续运行保留启动快照，未为早期运行补造快照。语义模块 hash：`00d18e0e4d96d383b5cc6ff0302f17e3d97d4afe26b1d9658ca6d6e128179a4f`。最终正文 grader hash：`800c1587be5d03881084029e1d02e3447911618216c6dc5a98125d76912617be`。数据 manifest hash：`c4180ed01d8f05d458b0c3a0c414379363e62d499babce4b02752a9e89512afc`。
